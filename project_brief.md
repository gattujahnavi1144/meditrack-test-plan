# MediTrack – Project Brief 
  
Description: A healthcare analytics platform that provides real-time insights 
into patient data for healthcare providers. 
Technology stack: React web front end, Python (FastAPI) REST APIs, PostgreSQL 
database, GitHub Actions for CI/CD. 
Users: Doctors, nurses, and hospital administrators on desktops, tablets, and 
mobile phones. 
  
Scope of testing: - Dynamic updates in data analytics (real-time dashboards) - UI responsiveness across devices and screen sizes - API security for patient-data integration and exchange 
  
Stakeholders: Development team, QA team, Project manager, Healthcare 
providers 
Timeline: 4 months
